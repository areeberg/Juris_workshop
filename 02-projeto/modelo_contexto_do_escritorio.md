# Modelo: contexto do escritório

Um arquivo `.md` que você anexa ao projeto. Responde à pergunta que a IA não tem como adivinhar: **como a nossa casa faz as coisas**. Sem ele, a IA completa com o que é comum na internet, que não é o que o seu escritório pratica.

Preencha uma vez. Atualize a cada trimestre. Não coloque dado de cliente aqui.

```markdown
# Contexto do escritório

## Quem somos
- Escritório de [tamanho] em [cidade/comarca]
- Áreas: [cível, consumidor, trabalhista, previdenciário...]
- Perfil de cliente mais comum: [pessoa física de renda média, pequeno comércio...]

## Padrão de honorários
- Modalidade preferida: [fixo / êxito / misto]
- Percentual de êxito padrão: [__ %]   (a IA nunca preenche este número sozinha)
- Entrada: [quando se cobra]
- Sucumbência: [de quem é]
- Despesas: [quem adianta]
- Forma de pagamento: [PIX, boleto, parcelado]

## Cláusulas que sempre entram
- Informação sobre uso de ferramentas de IA (texto em 05-conferencia/clausula_de_ia.md)
- Autorização para contato com terceiros indicados pelo cliente
- Obrigação de meio: nenhuma promessa de prazo ou resultado
- Foro: [comarca]

## O que nunca entra
- [Cláusula de exclusividade? Multa por desistência do cliente?]

## Modelos de peça do escritório
- Petição inicial: [nome do arquivo anexado]
- Contestação: [nome do arquivo anexado]

## Como falamos com o cliente
- Canal: [WhatsApp / e-mail / reunião]
- Tom: [direto, sem juridiquês, sem prometer resultado]
```
