# Conferência e registro

Os materiais desta pasta são usados antes, durante e depois do uso de IA.

- `seis_perguntas_de_risco.md`: antes de protocolar.
- `matriz_de_risco.md`: controles do escritório, revisão semestral.
- `pode_ou_nao_pode.md`: seis situações de decisão rápida.
- `clausula_de_ia.md`: texto para o contrato de honorários.
- `registro_de_uso.csv`: planilha mínima. Abra no Excel. Uma linha por uso, com o código do caso, nunca o nome do cliente.

As folhas de risco são adaptadas do trabalho de Graziela Bonfim, da Comissão de IA da OAB/RJ.
